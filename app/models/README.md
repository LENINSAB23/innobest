# Carpeta de Modelos YOLO - InnoBest Huánuco

Coloca aquí el archivo con los pesos del modelo entrenado de YOLO:

- **Nombre esperado**: `best.pt`
- **Ubicación exacta**: `app/models/best.pt`

### 3 Aves reconocidas:
1. **Gallito de las Rocas (Tunqui)** (*Rupicola peruvianus*)
2. **Matorralero Tricolor** (*Atlapetes tricolor*)
3. **Paujil** (*Crax globulosa / Mitu tuberosa*)

Una vez que descargues `best.pt` desde tu Google Drive y lo pegues en esta carpeta, la aplicación lo detectará automáticamente. Puedes pulsar el botón **"Recargar Modelo"** en la interfaz web o reiniciar el servidor con `python run.py`.
